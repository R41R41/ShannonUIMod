# ShannonUIMod

## 概要

**ShannonUIMod**は、Minebot「シャノン」の状態表示などをサポートする Minecraft 用 MOD です。  
タスクツリーやインベントリ、常時スキルなどの情報をゲーム内 UI で表示します。

## 主な機能

- Minebot「シャノン」のタスク進行状況や状態を UI で可視化
- タスクツリー、インベントリ、常時スキルのタブ切り替え表示
- サーバー側で HTTP サーバーを起動し、外部からタスク情報を受信・反映

## 対応バージョン

- Minecraft 1.21.4 以降
- Java 21 以降
- Fabric Loader 0.16.10 以降

## インストール方法

1. [Fabric API](https://modrinth.com/mod/fabric-api)を導入してください。
2. `mods`フォルダに本 MOD（`shannonuimod-x.x.x.jar`）を配置してください。

## 開発・ビルド

開発環境のセットアップ方法は[Fabric 公式ドキュメント](https://docs.fabricmc.net/develop/getting-started/setting-up-a-development-environment)を参照してください。
