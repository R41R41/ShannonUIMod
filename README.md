# ShannonUIMod

Minebot「シャノン」と一緒に遊ぶための Fabric MOD です。シャノンの状況をひと目で把握し、すぐに話しかけ、簡単に指示を出せます。

## 対応バージョン

- Minecraft 1.21.11
- Fabric Loader 0.18.1 以降、Fabric API
- Java 21

サーバーとクライアントの両方に入れて使います。MOD を入れていないクライアントも同じサーバーに参加できます。

## できること

| 画面 | 開き方 | 内容 |
|---|---|---|
| 状況カード | 常に表示 | 待機中・作業中・返事待ち・エラー・危ないの状態、目標、進み具合、いまの動作、距離と方角、体力と満腹度 |
| 頭の上の表示 | シャノンが見えているとき | 作業の進み具合と、シャノンの言葉の吹き出し。壁の向こうでは出ない |
| ロケーターバーの顔 | 常に表示 | バニラのロケーターバーで、シャノンの点を顔にする |
| すぐ話す | `Y` | 1行の入力欄。日本語入力と貼り付けに対応。返事待ちのときは返事の候補を数字キーで選べる |
| 指示メニュー | `G` | 止まって・ついてきて・こっちに来て・続けて・今の作業をやめる・持ち物を開く |
| 見ているものに指示 | スニークしながら `G` | 見ているブロックや敵について、掘って・同じ物を集めて・倒して・ここに来て・ここで待って |
| 詳細画面 | `U` | タスク（いまの作業と記録）・持ち物・お願い・スキル・会話・進捗・設定の7タブ。`U` でタブを切り替え |
| 押して話す | `B` を押している間 | Discord の音声をシャノンに送る。聞いている間と、聞き取った言葉を画面下に出す |

キーはすべて「設定 → 操作設定 → シャノン」で変えられます。

## 邪魔にならないために

ふだんのマイクラの画面をできるだけそのままにして、必要なときだけ出てくるようにしています。

- **状況カードは自動で大きさが変わります。** ふだんは1行です。作業が変わったときは8秒だけ大きくなり、返事待ち・失敗・危ないときは大きいままになります。`Tab`（プレイヤー一覧）を押している間も大きくなります。設定で「大きいまま」「顔だけ」も選べます。
- **通知は、見てほしいときだけ出します。** 返事待ち、失敗、体力が少ないときに攻撃されたとき（30秒に1回まで）だけです。作業が終わっただけでは出しません。
- **シャノンが見えているときは、言葉を頭の上に出します。** そのときはカードの下に同じ言葉を出しません。
- **押して話すの表示は、キーを押している間と、その後の数秒だけです。**
- 詳細画面と各画面は、開いたときだけ表示します。

## 設定

### サーバー: `config/shannonuimod.json`

すべて省略できます。

```json
{
  "backendHost": "localhost",
  "backendPort": 8092,
  "backendToken": "バックエンドの MINEBOT_API_TOKEN と同じ値",
  "httpServerPort": 8081,
  "httpServerBindAddress": "127.0.0.1",
  "botPlayerName": "I_am_Shannon",
  "debug": false
}
```

トークンは環境変数 `MINEBOT_API_TOKEN` でも渡せます。バックエンドからの受信口は、既定では同じマシンからの接続だけを受け付けます。

### クライアント: `config/shannonuimod-client.json`

状況カードの大きさと位置、吹き出し、頭の上の表示、ロケーターバーの顔、通知、よく使うお願いです。詳細画面の設定タブとお願いタブから変えられます。

## 他の MOD との共存

- Mixin を使っていません。体力や持ち物はサーバーの tick ごとに確認して、変化したときだけ送ります。
- HUD は Fabric API の HUD 要素として登録しているので、HUD を並べ替える MOD からも扱えます。F1 と F3 では隠れます。
- 頭の上の表示はワールドの描画に手を入れず、HUD にシャノンの位置を写して描きます。シェーダーや描画を変える MOD と競合しません。
- ロケーターバーの顔は、バニラと同じ計算で点の位置に重ねるだけです。バニラがバーを出していないときは出しません。
- 状況カードは左上か右上を選べます。ミニマップなどと重なるときに切り替えてください。
- 画面はバニラのボタン、スライダー、テキスト欄、ツールチップ、トーストを使っています。リソースパックの見た目にも追従します。
- キーは画面を開いていないときだけ反応するので、他の MOD の画面での入力を邪魔しません。
- 通信は1種類の汎用パケットにまとめ、プロトコルの版をチャンネル名に含めています。版が違う相手とは通信しないので、切断は起きません。

## 構成

```
src/main
  model/      同期する状態のデータ型（UI の処理を持たない）
  sync/       状態チャンネルと操作チャンネルの定義、汎用パケット
  server/     状態の配信、クライアントからの操作の処理、ボットの観察
  state/      サーバー側の状態の正本
  http/       バックエンドからの受信口
  client/     バックエンドへの送信（専用スレッド）
src/client
  ui/state    クライアント側の状態と、そこから導く状態（待機中・作業中・返事待ち・エラー、危ない、作業の記録）
  ui/gfx      バニラの部品を再現する描画部品とドット絵アイコン
  ui/hud      状況カード、吹き出し、頭の上の表示、ロケーターバーの顔、押して話す、通知
  ui/screen   すぐ話す、指示メニュー、詳細画面と各タブ
  ui/input    キー、見ているものの判定
```

状態を1つ増やすときは、`model` にデータ型を作り、`sync/StateChannels` に1行足します。操作を1つ増やすときは、`sync/Actions` に1行足し、`server/ServerActions` に処理を1つ登録します。タブを1つ増やすときは、`ShannonTab` を継承したクラスを作り、`ShannonScreen#createTabs` に1行足します。

## バックエンドとの対応

ボット本体（`R41R41/Shannon`）のブランチ `codex/shannonuimod-v2-bridge` に、この MOD 用の対応を入れています。

- **指示メニュー**は `POST /bot_command` に送ります。止まる・ついていく・来る・続ける・やめるは、ボット側で決まった操作として実行されます。古いボット本体では 404 になるので、そのときは以前の方法に切り替えます。
- **見ているものへの指示とお願い**は、座標とブロックの ID を含めた文章として `POST /chat_message` に送ります。ボット本体の変更はいりません。
- **返事待ちのとき**、すぐ話す欄と会話タブの入力は、ゲーム内チャットに「シャノン、」を付けて送ります。シャノンが質問したのと同じ場所で答えるためです。それ以外のときは MOD の経路で送ります。
- **返事の候補**は、`/task` の `replyChoices`（文字列の配列）があればそれを、なければ「いいよ・だめ・おまかせ」を出します。
- **返事待ちの状態**は、`/task` の `recoveryStatus` か `/task_list` の `currentRecoveryStatus` が `awaiting_user` のときに表示します。タスクがどう終わったかは `/task_list` の `currentTaskTree` からも拾います。
- **押して話す**は、`/voice_ptt` の応答（`blocked`、`blockedBy`、`success`）で「聞いています」「ほかの人が話しています」「ボイスチャンネルにいません」を出し分けます。聞き取った言葉は、ボット本体が `POST /voice_transcript` に `{text, mcUsername, mode}` で送ります。MOD はその名前のプレイヤーにだけ届け、オンラインでなければ捨てます。
- **危ない**の表示は、MOD のサーバー側で、シャノンがダメージを受けたことと相手を Fabric のイベントで知って出します。ボット本体の変更はいりません。
