# ShannonUIMod

Minebot「シャノン」と一緒に遊ぶための Fabric MOD です。シャノンの状況をひと目で把握し、すぐに話しかけ、簡単に指示を出せます。

## 対応バージョン

- Minecraft 1.21.11
- Fabric Loader 0.18.1 以降、Fabric API
- Java 21

サーバーとクライアントの両方に入れて使います。MOD を入れていないクライアントも同じサーバーに参加できます。

## できること

| 画面 | 開き方 | 内容 |
|---|---|---|
| 状況カード | 常に表示 | 待機中・作業中・返事待ち・エラーの状態、目標、進み具合、いまの動作、距離と方角、体力と満腹度 |
| 吹き出し | 自動 | シャノンの発言をカードの下にしばらく表示 |
| すぐ話す | `Y` | 1行の入力欄。日本語入力と貼り付けに対応 |
| 指示メニュー | `G` | 止まって・ついてきて・こっちに来て・続けて・今の作業をやめる・持ち物を開く |
| 詳細画面 | `U` | タスク・持ち物・スキル・会話・進捗・設定の6タブ。`U` でタブを切り替え |
| 押して話す | `B` を押している間 | Discord の音声をシャノンへの指示として送る |

キーはすべて「設定 → 操作設定 → シャノン」で変えられます。返事待ちとエラーのときは、画面右上に通知が出ます。

## 設定

### サーバー: `config/shannonuimod.json`

すべて省略できます。

```json
{
  "backendHost": "localhost",
  "backendPort": 8092,
  "backendToken": "バックエンドの MINEBOT_API_TOKEN と同じ値",
  "httpServerPort": 8081,
  "httpServerBindAddress": "127.0.0.1",
  "botPlayerName": "I_am_Shannon",
  "debug": false
}
```

トークンは環境変数 `MINEBOT_API_TOKEN` でも渡せます。バックエンドからの受信口は、既定では同じマシンからの接続だけを受け付けます。

### クライアント: `config/shannonuimod-client.json`

状況カードの位置、吹き出し、通知の有無です。詳細画面の設定タブから変えられます。

## 他の MOD との共存

- Mixin を使っていません。体力や持ち物はサーバーの tick ごとに確認して、変化したときだけ送ります。
- HUD は Fabric API の HUD 要素として登録しているので、HUD を並べ替える MOD からも扱えます。F1 と F3 では隠れます。
- 状況カードは左上か右上を選べます。ミニマップなどと重なるときに切り替えてください。
- 画面はバニラのボタン、スライダー、テキスト欄、ツールチップ、トーストを使っています。リソースパックの見た目にも追従します。
- キーは画面を開いていないときだけ反応するので、他の MOD の画面での入力を邪魔しません。
- 通信は1種類の汎用パケットにまとめ、プロトコルの版をチャンネル名に含めています。版が違う相手とは通信しないので、切断は起きません。

## 構成

```
src/main
  model/      同期する状態のデータ型（UI の処理を持たない）
  sync/       状態チャンネルと操作チャンネルの定義、汎用パケット
  server/     状態の配信、クライアントからの操作の処理、ボットの観察
  state/      サーバー側の状態の正本
  http/       バックエンドからの受信口
  client/     バックエンドへの送信（専用スレッド）
src/client
  ui/state    クライアント側の状態と、そこから導く「待機中・作業中・返事待ち・エラー」
  ui/gfx      バニラの部品を再現する描画部品とドット絵アイコン
  ui/hud      状況カード、吹き出し、通知
  ui/screen   すぐ話す、指示メニュー、詳細画面と各タブ
```

状態を1つ増やすときは、`model` にデータ型を作り、`sync/StateChannels` に1行足します。操作を1つ増やすときは、`sync/Actions` に1行足し、`server/ServerActions` に処理を1つ登録します。タブを1つ増やすときは、`ShannonTab` を継承したクラスを作り、`ShannonScreen#createTabs` に1行足します。

## バックエンドとの対応

ボット本体（`R41R41/Shannon`）のブランチ `codex/shannonuimod-v2-bridge` に、この MOD 用の対応を入れています。

- **指示メニュー**は `POST /bot_command` に送ります。止まる・ついていく・来る・続ける・やめるは、ボット側で決まった操作として実行されます。古いボット本体では 404 になるので、そのときは以前の方法に切り替えます。
- **返事待ちのとき**、すぐ話す欄と会話タブの入力は、ゲーム内チャットに「シャノン、」を付けて送ります。シャノンが質問したのと同じ場所で答えるためです。それ以外のときは MOD の経路で送ります。
- **返事待ちの状態**は、`/task` の `recoveryStatus` か `/task_list` の `currentRecoveryStatus` が `awaiting_user` のときに表示します。タスクがどう終わったかは `/task_list` の `currentTaskTree` からも拾います。
